# Archived and not-used scripts

This folder contains scripts retained for transparency but not used in the current revised manuscript package.

These files are historical or exploratory scripts. They are not part of the active analysis workflow, are not required to reproduce the submitted manuscript figures or tables, and should not be cited as evidence for the submitted manuscript.

## Archived analyses

The following categories are archived:

- GSE125449-related validation scripts;
- legacy GSE235863 ROC/AUC, drug-repurposing, or treatment-selection scripts;
- ENO1-centered restoration scripts;
- historical figure-restoration scripts that are not authoritative for the current Figure 1-7 workflow.

## Interpretation boundary

Archived scripts do not support any active manuscript claim.

In particular:

- GSE125449 is not used in the current revised manuscript package;
- GSE235863 is used only for exploratory association analysis in the active workflow;
- no ROC, PR, DCA, complex machine learning, treatment-selection model, or clinical decision model is supported by the archived GSE235863 scripts;
- ENO1 is not treated as a stand-alone mechanistic driver or single-gene main theme.

The active analysis workflow is documented in the root-level `README.md`, `RUN_ORDER.md`, `CODE_AVAILABILITY_NOTE.md`, and `MANUSCRIPT_TO_REPOSITORY_MAP.tsv`.
