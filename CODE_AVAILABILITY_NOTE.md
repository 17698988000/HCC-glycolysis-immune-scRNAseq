# Code availability note

Analysis scripts, compact locked source tables, and reproducibility documentation are available in this repository.

## Included

- Active R scripts under `scripts/`
- Authoritative submission-locked compact source tables under `locked_source_data/`
- Current author environment snapshot under `reproducibility/`
- Historical scripts retained separately under `archive_not_used/`

## Excluded

Large downloaded public datasets, intermediate RDS objects, and generated manuscript figures are not committed. Public dataset accessions are documented in the manuscript and README. Manuscript figures are submitted separately.

## Environment snapshot note

The files in `reproducibility/` capture the author's current R environment at repository-cleanup time. They are provided transparently and may differ from the original analysis environment reported in the manuscript. The manuscript remains the authoritative record of the analysis environment used for the study.
