# Locked source data

This directory contains compact authoritative source tables aligned to the submission release. These files are included to make key manuscript conventions auditable without committing large intermediate RDS objects.

## Directory contents

- `single_cell/`: Figure 2C rank-balanced GlycoHigh/GlycoLow assignment and technical-sensitivity source table
- `ligand/`: Figure 3 / Supplementary Table S3 patient-aware ligand source tables
- `lasso/`: locked four-gene coefficients and repeated-CV / bootstrap stability summaries
- `supplementary_figures/`: locked compact source table for Supplementary Figure S15 redraw
