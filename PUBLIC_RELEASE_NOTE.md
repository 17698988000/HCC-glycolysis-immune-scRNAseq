# Public submission release note

This candidate repository is the public-facing submission package.

Included:
- active numbered analysis scripts;
- compact locked source tables;
- reproducibility notes and environment snapshots;
- manuscript-to-repository mapping;
- MIT License and citation metadata.

Excluded:
- raw public-data downloads;
- large intermediate RDS objects;
- generated manuscript figure files;
- revision-era scripts and superseded figure-restoration helpers.

Historical exclusions are listed in `archive_not_used/ARCHIVED_ITEMS_MANIFEST.csv`.
