# Public submission revision release note

This repository is the public-facing submission revision package.

Included:
- active numbered analysis scripts;
- revision-stage scripts under `scripts/revision/`;
- compact revision-stage expected outputs under `expected_outputs/revision/`;
- compact locked source tables under `locked_source_data/`;
- reproducibility notes and environment snapshots;
- manuscript-to-repository mapping;
- recommended execution order;
- MIT License and citation metadata.

Excluded:
- raw public-data downloads;
- Visium image files;
- TCGA/Xena downloads;
- large intermediate RDS objects;
- local cache files;
- generated manuscript figure files.

The final submission revision release is `v1.0.3-submission-revision-final-clean`.

This repository supports reproducibility and auditability of the submitted manuscript. It does not provide a clinical assay, validated prognostic classifier, treatment-response predictor, or mechanistically validated ligand-receptor model.
